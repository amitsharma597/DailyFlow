# TodoApp 📝

A responsive Todo application built with HTML, CSS, and Vanilla JavaScript. Users can add tasks, delete tasks, mark them as completed, switch between light and dark themes, and manage their daily tasks with persistent storage using Local Storage.

## Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🌙 Toggle between Light and Dark themes
- 💾 Save tasks using Local Storage
- 📋 Display all tasks
- 📊 Show total task count
- ⏳ Show pending task count
- ✔️ Show completed task count
- 📱 Responsive design for desktop, tablet, and mobile devices

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Local Storage API

## Installation

Clone the repository

```bash
git clone https://github.com/amitsharma597/todo-app.git
```

Navigate to the project folder

```bash
cd todo-app
```

Open `index.html` in your preferred web browser.

## How It Works

1. User enters a task.
2. The task is added to the task list.
3. Tasks can be marked as completed or deleted.
4. The application automatically updates the total, pending, and completed task counts.
5. Users can switch between Light and Dark themes.
6. All tasks are stored in Local Storage and restored when the application is reopened.
